پروژه سایت ارتباطی عطریات آرام
================================

فایل‌ها:
- index.html: ساختار صفحه
- style.css: طراحی واکنش‌گرا، رنگ‌بندی و انیمیشن لوگو
- script.js: شمارش معکوس و ذخیره مخاطب
- assets/aram-perfumes-logo.png: لوگوی ارائه‌شده

انتشار روی GitHub Pages:
1. همه فایل‌ها و پوشه‌ها را در یک مخزن GitHub آپلود کنید.
2. از Settings > Pages، شاخه اصلی (معمولاً main) و پوشه /(root) را انتخاب کنید.
3. سایت پس از فعال شدن GitHub Pages در دسترس خواهد بود.

زمان تایمر:
16 دسامبر 2026، ساعت 09:00 افغانستان (UTC+04:30)، معادل 2026-12-16T04:30:00Z.
تایمر بر اساس ساعت دستگاه بازدیدکننده اجرا می‌شود؛ بنابراین ساعت دستگاه باید دقیق باشد.
پس از زمان هدف، متن «شروع زمان چاش» به مدت 10 ساعت نمایش داده می‌شود و سپس باکس پنهان می‌شود.

حذف کامل تایمر:
در index.html کل بخش <section class="countdown-card" id="countdownBox"> ... </section> را حذف کنید.
در صورت حذف این بخش، بهتر است بخش مربوط به تایمر در script.js نیز حذف شود.

فونت Peyda:
CSS برای فونت Peyda آماده است. فایل‌های قانونی فونت وب را در پوشه fonts قرار دهید و در style.css نام فایل‌ها را با نام واقعی فایل‌های خود هماهنگ کنید:
- PeydaWeb-Regular.woff2
- PeydaWeb-Medium.woff2
- PeydaWeb-Bold.woff2

اگر فایل فونت در دسترس نباشد، سایت با فونت جایگزین فارسی (Tahoma) نمایش داده می‌شود.
